Autenticación

Tres pasos para tu primer token

Todo endpoint transaccional exige un Bearer Token válido. El flujo sigue el estándar OAuth 2.0 client-credentials, pensado para integraciones servidor-a-servidor.

01

Registra tu aplicación

Obtén un client_id y client_secret desde el panel de comercios.

02

Solicita el token

Intercambia tus credenciales por un JWT de corta duración.

POST /oauth2/token
03

Autoriza tus peticiones

Adjunta el token en cada llamada a la Gateway.

Authorization: Bearer <jwt>
Endpoints principales

Dos operaciones, dos contratos distintos

Una consulta síncrona de bajo riesgo y una orden de pago asíncrona que entra a cola — cada una con su propio código de estado y su propio compromiso de disponibilidad.

GET/api/v1/cuentas/saldos

Consultar saldos y movimientos

Retorna el estado consolidado de la cuenta. Responde 200 de forma síncrona, 401 si el token es inválido o expiró.

{ "balanceDisponible": 45800.5, "moneda": "PEN", "estadoCuenta": "Activo" }
POST/api/v1/pagos/transferir

Procesar transferencia

Inyecta una orden de pago en el libro contable digital. Responde 202: queda en cola para procesamiento batch.

{ "transaccionId": "TX-9938210-UUID", "estado": "Procesando (En Cola)" }
